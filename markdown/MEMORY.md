## ⑧ 验证习惯（展开版 = `RULES.md` 六；通用手法在技能 `verify-single-file-html-app`）

- ⚠ **「发生了」必须配「不该发生」的对照组**，否则可能**永远为真**；⚠⚠ **但对照组必须「不同」** —— A 与 B 碰巧同串时两条取值路径读出同一个值，**删掉实现照样全绿**（六之二十六）。⚠⚠ **「取不到就换一个」的回落 = 把失败伪装成成功** ⇒ **回落必须说出来**（六之二十七）。⚠ **断言方向本身就是需求** ⇒ 改主意**先改断言、看它红，再改产品**。⚠ **数组不能用 `===` 比**；**折叠面板的「看不见」rect 量不出** ⇒ 用命中测试。
- ⚠⚠ **「跑完了」≠「每条都跑到了」**（提前 `process.exit()` 静默吃掉后面）；⚠ **「从来没发生过」要拿当时的快照支撑**，不能靠回忆 ⇒ **锚点一律选结构性的**。
- ⚠⚠ **写死清单 / 写死数字每次加东西都会来收账** ⇒ **改推导式 / 跟基线比**（最阴：遍历清单是字面量数组 ⇒ **根本不红、只静默少走**）；⚠⚠ **顺序型断言有三种静默形态**（六之十七），**都不会当场红**，必须人工核。⚠ **探针造的文件无条件删**；**改了断言名要重跑对着它的反向测试**。⚠⚠ **新断言要「崩不掉」但又不能「永远为真」** —— 注入后抛异常会让套件**当场炸掉、连汇总行都没有**（那一针等于白跑）⇒ 读数组元素一律 `(a[i] || {})`；⚠⚠ **但 `[].every()` / `[].some()` 对空数组有定义好的返回值** ⇒ 光加 `|| []` 会让断言**天生为真**（六之三十九）⇒ 一律改成**「数出来跟期望比」**。⚠⚠ **连带红要一条不落地写进 `red`**；⚠ **「对照」不等于「必然绿」**（六之二十九）。
- ⚠⚠ **新增功能可能让旧套件的「前提」失效，而不是打坏产品** —— 断言**集体假红**时**看数值是不是全 0**（全 0 = 元素不可见）⇒ **让断言走真实路径**。⚠ **靠 class 变 `position:fixed` 的卡片隐藏必须写 `:not(.全屏类)`**，且**断言 computed `display`**。⚠⚠ **`hidden` 属性同样会被同权重的 `display:flex` / `grid` 盖掉**（`el.hidden = true` **完全无效、不报错**）⇒ 兜底写成**全局一条** `[hidden]{display:none!important}` —— **「哪几处需要」这个判断自己就会漏**（逐条补踩过两次），判据同样**读 computed `display` 不读属性**（六之四十四）。
- ⚠ **`saki.html` 是 CRLF** ⇒ JS 里 `.` **不匹配 `\r`**，`$` 锚行尾的正则**整条静默失败**；⚠⚠ **`\r` 也会从运行时数据进来**（模型输出 / `fetch` / 旧 `localStorage`）⇒ 用 `$` 或按行切的正则**进函数先归一 `\r\n?`→`\n`**（六之二十八）。⚠ Git Bash `grep -c $'\r'` 对 CRLF 报 0（**不可靠**）⇒ Node 读 `latin1` 后 `match(/\r\n/g)`。⚠ `markdown/` 是**纯 LF**。
- ⚠ **`check.js` 改完先跑**：`SYNTAX` / `MISSING` / `DUPLICATE literal ids` / `UNDECLARED` / `ESCAPE-GATE`。⚠ **它读页面不读生成物**（**过时的输入比没有检查更坏**）；**新加构建函数必须来改 `ESCAPE_ALLOW` 白名单**。
- ⚠ **整跑一律用 `run-all.js`**（手写 `for` + `grep`/`tail` 会让格式不匹配的那几套**静默变空行**）。⚠⚠ **它抓不到「某套只跑了一部分」** ⇒ **harness 一律串行**（**同一套也别并发**）、timeout **≥ 900 s**，跑完**拿逐套数字跟 `README` §7 表对一遍**。⚠⚠ **本环境 `spawnSync` / `execFileSync` / `execSync` 一律 `EBUSY`**（异步 `spawn` 正常）⇒ 整跑／lint／反向测试**只能用异步 `spawn`**；⚠ **两处 `_verify` 各有一份驱动，改要改两份**；老 `_reverse*.js`（**14 套**）仍写同步 API（六之四十六）。
- ⚠ **Chrome 层超时 / 报「`NOT FOUND` 锚点变了」时，先量网络、先去产品里 `grep` 那个锚点，别先怀疑产品**（主页 `@import` 拉 Google Fonts ⇒ 超时**假红**）；判回归**拿改动前的副本跑同一个 harness**。（探针收尾的 `kill()` / profile 顺序 / 句柄作用域在技能里，不重复）⚠⚠ **但套件收尾的 `rmSync(profile)` 会卡死整层** —— 本机删一个文件 ~200 ms，几百文件的 profile **永不返回**；⚠⚠ **汇总行写在 `finally` 之后** ⇒ 卡住就**连汇总行都没有**（反向测试拿不到「红了几条」）⇒ 一律派 `spawn(detached)` 删（`home-verify.js` 已修；⚠⚠ **余 28 个仍用 `rmSync`，实测确实会卡** —— `smoke` / `persona-verify` / `st-code` 三套都是「断言全绿后卡住」，后两套**连汇总行都打不出来** ⇒ **该改，只是优先级低于产品**）。
- ⚠⚠ **「猜」和「决议」是两步 ⇒ 断言要打在真正决定行为的那一步**（只测「猜」会让真 bug 全绿；「量得没错但量错了对象 = 没量」），且**「只有它能答」这个说法自己也要核**（六之三十三）。⚠⚠ **「这一步没做」的路径必须自己喊出来**，静默降级成另一种协议比直接报错难查得多（六之三十五）。⚠ **文档里写死的数字要么改推导式、要么配一条断言盯着** —— 「找不到就跳过」是把失败伪装成成功（六之三十六）。⚠⚠ **外部 API「形状对」≠「那个方法存在」** ⇒ 拼 URL 前先核**那条资源的方法清单**；**从同类产品抄不到，说明这条路是自己加的、更没有保险**（六之四十三）。
- ⚠⚠ **「过时断言」是「永真断言」的镜像** —— 产品改了**人话**（报错文案）、断言没跟着改 ⇒ 套件**一直红**（永真是**一直绿**），而红久了没人看（`st-ai` 那条漂了一整轮，整跑才翻出来）。⚠⚠ **`grep` 产品会骗人**：旧串往往**还剩在注释里**（`grep -c` 返回 1，看着像「还在产品里」）⇒ 只能**跑一遍看它红**。断言引用人话时**只守语义不守整句**，但别宽到「抛错就算过」（六之四十八）。⚠⚠ **「注入点唯一」这道闸门挡不住「没人跑」** —— `_reverse14` R4 把产品文案写进 `from` ⇒ 命中 0 次 ⇒ **静默空操作**漂一轮（闸门本身是好的，但那套用 `spawnSync`、本机跑不起来）⇒ 探针的 `from` 选**结构性**的（函数名 / 调用点 / 代码骨架），**别选人话**（六之四十九）。
- ⚠⚠ **harness 自己的结构缺陷会伪装成「产品坏了」**：端口写死 / 盲等 `sleep` ⇒ `vertex-verify` 打 **`1 通过 / 1 失败`**，而那**唯一通过的恰恰是「零异常」**（什么都还没跑）⇒ **「通过数 = 1」且那条是零报错时，先怀疑加载没完成**；**「假红」必须靠「同一套单跑是绿的」证伪**，不能靠「我觉得是环境」（六之五十）。⚠⚠ **驱动坏掉 = 全部 `0.0s` + 每套 `[无]`**（`0.0s` 是唯一线索）—— ⚠ **同一件事有几份实现就要改几份**（本地那份改了、外部那份漏了，外部 8 层就整层跑空）（六之五十一）。⚠ **表里的数字有两种**：写死的会红，**推导的永远不会红**（`smoke.js` 90→91 = 每条选项卡一次断言）⇒ 只能**拿实测跟表对**（六之五十二）。
- ⚠⚠ **别在反向测试跑着的时候改产品** —— 它从内存基线写回磁盘，你的改动会被**静默盖掉**；kill 后留下 `.bak`（干净基线）+ **一份被注入过的产品**（`grep "注入："` 核），套件下次会拒绝跑（那是对的）（六之三十四）。⚠ **模板字符串里出现反引号**（哪怕在注释里）会把字符串提前结束，报错却指向**函数开头** ⇒ 改完套件先跑 `_verify/_lint-suites.js`（六之三十七）。⚠ **注入要窄到只打它声称打的那件事**（整块替换会把对照组一起打红）；⚠ **一份逻辑 N 份实现 ⇒ 探针逐针点名跑哪一套**（六之四十一 / 四十二）。⚠ **「函数写好了」≠「被调用了」** —— 静态检查与行为断言**都看不见**零调用点 ⇒ 覆盖盯**调用点**、拿场景走**真实请求路径**（六之四十）。⚠ **两份实现还要逐份核「调用点传的参数」** —— 可选参数只传了一份 ⇒ 那侧**静默失效**（功能等于废掉，界面只表现为「点了没反应」）（六之四十五）。

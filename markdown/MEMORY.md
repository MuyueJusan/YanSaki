## ⑧ 验证习惯（展开版 = `RULES.md` 六）

> ⚠ **通用手法已收进用户级技能 `verify-single-file-html-app`**；这里只留**项目特有**的。

- ⚠ **「某件事发生了」必须配「这件事不该发生」的对照组** —— 否则它可能**永远为真**。⚠ **断言的方向本身就是需求**：用户改主意时**先改断言、看它红，再改产品**。⚠ 折叠面板（`0fr` + `overflow:hidden`）**裁切不影响 `getBoundingClientRect()`** ⇒ 判「看不见」要**命中测试**。⚠ **数组不能用 `===` 比**。⚠ `check(name, actual, pred, expect)` **只收 4 个参数** —— 函数谓词按正断言的形状写成 5 个时 `pred` 成了字面量，`11 === 1` 当场红（第 12 轮实测）。
- ⚠⚠ **反向测试的 `red`/`green` 名单是手抄的，手抄的会漂** ⇒ 跑探针**之前**先核「这些名字基线里真的 ✅ 过吗」，对不上**直接退出**（省掉后面 5 次整跑）。⚠ **`green` 里放不存在的名字最阴** —— 「对照组一条都没红」**天然成立**。⚠ 抽 ✅ 名字**两边都要 `trim`**；⚠ **失败项列表符两套件不一样**（`-` vs `·`）。⚠ **改了靶子套件的断言名，要重跑对着它的反向测试**。
- ⚠ **反向测试要注入到产品里**（撤掉修复重跑，确认**恰好那几条**变红、对照仍绿）；⚠ **注入器要自包含**（备份→注入→断言→还原→核字节）；**跑完必核产品哈希**。⚠ **探针粒度落在行为上，不落在实现细节上**（第 10 轮 R4 落在实现细节上，注入后**全绿**）。
- ⚠⚠ **绿 ≠ 验证过了，只等于「这次没红」—— 反向测试要定期重跑**。⚠ **「跑完了」≠「每条都跑到了」**（提前 `process.exit()` 静默吃掉后面）。⚠ **「从来没发生过」要拿当时的快照支撑，不能靠回忆**（漏语句两种形态：没落盘 / 落盘后被后续批量覆盖 —— 事后 grep 一模一样）。**锚点一律选结构性的。**

**快路径 `check.js`（`G:\saki\_verify\`）**
- 改完先跑 `node check.js`：自己抽 `saki.html`、自己 `vm.Script` 解析，**不用先 `extract.js`**。**5 项**：`SYNTAX` / `MISSING` / `DUPLICATE literal ids` / `UNDECLARED` / `ESCAPE-GATE`。⚠ **它读的是页面不是生成物** —— **过时的输入比没有检查更坏**。
- ⚠ **转义闸门**判据 = 抹白已安全包装后剩下的 `+ 变量` **多重集**跟 `ESCAPE_ALLOW` 逐字一致（**新加构建函数必须来改白名单**）。⚠ **两种「已声明」口径不能混用**。

**跑套件**
- ⚠ **整跑一律用 `run-all.js`**，别手写 `for` + `grep`/`tail`（汇总行两种格式，只匹配一种会让那几套**静默变空行**）。**「看得见」≠「检查过」。** ⚠ runner 把三件事变**硬错误**：收尾行解析不出 / 目录里有未分类 `.js` / 有失败项；⚠ **故意不写死期望总数**；⚠ **枚举不完整时不会红，只会少走**；⚠ **改了哪个套件就单跑哪个**。⚠ **外部那份多一道 `BAD-SUMMARY`**（汇总行算出来是负数 / 分母 0 ⇒ 硬错误；`-1/0` 被正则啃成 `1/0` ⇒ `fail = -1` ⇒ **整层跑空却打 ✅**）；本地 16 套不需要。
- ⚠⚠ **但它抓不到「某套只跑了一部分」** —— 实测**并行跑两套 harness** 时外部 Chrome 层只跑了 **1/371**、汇总行照样解析得出、runner 照样打「✅ 全部通过」。⇒ **两套 harness 一律串行**、各自 timeout **≥ 900 s**（本地单套上限已提到 **15 min**）；跑完**拿逐套数字跟 `README` §7 表对一遍**。
- ⚠ **管道之后的 `$?` 是 `tail` 的退出码，不是被测进程的** ⇒ 要量被测进程就**分开跑**。**量错了对象 = 没量。**
- ⚠⚠ **`Page.loadEventFired` 等不到时，先量网络，别先怀疑产品。** 主页一条 `@import` 拉 Google Fonts（3 字族 → **24 个 `.woff2`**），当前网络一个请求约 4 s ⇒ 导航超时**假红**（`readyState` 停在 `interactive`，页面完全正常）。⚠ **判是不是回归：拿改动前的副本跑同一个 harness** —— 两边都卡 = 环境。已抽 `NAV_LOAD_TIMEOUT = 60000`。
- ⚠ **`NOT FOUND —— 锚点变了` 时，先去产品里 `grep` 那个锚点，再改探针**（「代码不在」和「代码挪了」从探针这侧看**一模一样**）。⚠ **探针收尾：`kill()` 在前、删 profile 在后**，句柄挂**模块作用域** —— `.finally()` 的回调**看不见** async IIFE 里 `const` 的变量，`try{ch.kill()}catch{}` 吞的是 `ReferenceError`，**长得跟「清理成功」一样**。

**这个项目特有的坑**
- ⚠ **`saki.html` 是 CRLF**，JS 里 `.` **不匹配 `\r`** → `/\/\/.*$/` **整条匹配失败**（不报错，只安静给出错的数）。**凡是用 `$` 锚行尾的正则，先问「这文件是 CRLF 吗」。** ⚠ Git Bash 的 `grep -c $'\r'` 对 CRLF 会报 0（**不可靠**）—— 要数就 Node 读 `latin1` 后 `match(/\r\n/g)`。⚠ `markdown/` 是**纯 LF**，别一起当 CRLF 处理。
- ⚠⚠ **写死清单 / 写死数字的断言每次加东西都会来收账** ⇒ **改推导式 / 跟基线比**。⚠⚠ **顺序型断言有三种静默形态**（`RULES.md` 六之十七）：① 遍历清单是**字面量数组**，新项不在里面 → **根本不会红**，只是静默少走；② **子串正则**（`/sb,code,export/` 在 `…sb,code,persona,export…` 上**照样匹配**）→ 新项**静默漏出覆盖**；③ **相邻距离写死** → 会红，但要**补一条反向对照**。⚠ **探针自己造的文件要无条件删**。⚠ 套件时序坑（`ev(..., true)` 不等 Promise / mock 与 `stream` 要一起改）见 `RULES.md` 六。
- ⚠⚠ **新增功能可能让旧套件的「前提」失效，而不是打坏产品。** 手机菜单让 `#ai-card` 在手机视口下默认 `display:none` ⇒ 外部层那些「移动端触控尺寸」断言**集体假红**（rect 全 0）。判据：**看数值是不是全 0** —— 全 0 通常意味着「元素不可见」，不是「尺寸不达标」；修法是**让断言走真实路径**，不是把产品改回去。
- ⚠ **隐藏一个靠 class 变 `position:fixed` 的卡片，必须写 `:not(.全屏类)`** —— 否则全屏被 `display:none` 一起压掉，而 class 照样加得上 ⇒ **只断言 class 抓不到，必须断言 computed `display`**。

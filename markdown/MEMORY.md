## ⑧ 验证习惯（展开版 = `RULES.md` 六；通用手法在技能 `verify-single-file-html-app`）

- ⚠ **「发生了」必须配「不该发生」的对照组**，否则**永远为真**；⚠⚠ **对照组必须「不同」**（同串 ⇒ 两条路径读同一个值 ⇒ 删掉实现照样绿，六之二十六）。⚠⚠ **「取不到就换一个」的回落 = 把失败伪装成成功** ⇒ **回落必须说出来**（六之二十七）。⚠ **断言方向本身就是需求** ⇒ 改主意**先改断言、看它红，再改产品**。⚠⚠ **「跑完了」≠「每条都跑到了」**（提前 `process.exit()` 静默吃掉后面）；**「从来没发生过」要拿当时的快照支撑** ⇒ **锚点一律选结构性的**。⚠ 数组不能 `===` 比；**折叠面板的「看不见」rect 量不出** ⇒ 命中测试。
- ⚠⚠ **写死的清单 / 数字每次加东西都会来收账** ⇒ **改推导式 / 跟基线比**（最阴：遍历清单是字面量数组 ⇒ **不红、只静默少走**）；⚠⚠ **顺序型断言有三种静默形态**（六之十七），**都不会当场红**，必须人工核。⚠ **探针造的文件无条件删**；**改了断言名要重跑对着它的反向测试**。⚠⚠ **新断言要「崩不掉」又不能「永远为真」** —— 注入后抛异常会让套件**当场炸掉、连汇总行都没有** ⇒ 读数组元素一律 `(a[i] || {})`；⚠⚠ **但 `[].every()`/`[].some()` 对空数组有定义好的返回值** ⇒ 光加 `|| []` 会让断言**天生为真**（六之三十九）⇒ **改成「数出来跟期望比」**。⚠⚠ **连带红要一条不落地写进 `red`**；⚠ **「对照」≠「必然绿」**（六之二十九）。
- ⚠⚠ **新增功能可能让旧套件的「前提」失效，而不是打坏产品** —— 断言**集体假红**时**看数值是不是全 0**（全 0 = 元素不可见）⇒ **让断言走真实路径**。⚠ **靠 class 变 `position:fixed` 的卡片隐藏必须写 `:not(.全屏类)`**。⚠⚠ **`hidden` 属性会被同权重的 `display:flex`/`grid` 盖掉**（`el.hidden = true` **完全无效、不报错**）⇒ 兜底写**全局一条** `[hidden]{display:none!important}`（「哪几处需要」这个判断自己就会漏）⇒ 判据**读 computed `display`**（六之四十四）。
- ⚠ **`saki.html` 是 CRLF** ⇒ JS 里 `.` **不匹配 `\r`**，`$` 锚行尾的正则**整条静默失败**；⚠⚠ **`\r` 也会从运行时数据进来**（模型输出 / `fetch` / 旧 `localStorage`）⇒ 用 `$` 或按行切的正则**进函数先归一 `\r\n?`→`\n`**（六之二十八）。⚠ Git Bash `grep -c $'\r'` 对 CRLF 报 0（**不可靠**）⇒ Node 读 `latin1` 后 `match(/\r\n/g)`。⚠ `markdown/` 是**纯 LF**。
- ⚠ **`check.js` 改完先跑**：`SYNTAX` / `MISSING` / `DUPLICATE literal ids` / `UNDECLARED` / `ESCAPE-GATE`。⚠ **它读页面不读生成物**（**过时的输入比没有检查更坏**）；**新加构建函数必须来改 `ESCAPE_ALLOW` 白名单**（点名制，不加 = 永远不看）。
- ⚠ **整跑一律用 `run-all.js`**（手写 `for` + `grep`/`tail` 会让格式不匹配的那几套**静默变空行**）。⚠⚠ **它抓不到「某套只跑了一部分」** ⇒ **harness 一律串行**、timeout **≥ 900 s**，跑完**拿逐套数字跟 `README` §7 表对一遍**。⚠⚠ **本环境 `spawnSync`/`execFileSync`/`execSync` 一律 `EBUSY`** ⇒ 整跑／lint／反向测试**只能用异步 `spawn`**；⚠ **两处 `_verify` 各有一份驱动，改要改两份**；老 `_reverse*.js`（14 套）仍写同步 API（六之四十六）。
- ⚠ **Chrome 层超时 / 报「`NOT FOUND` 锚点变了」时，先量网络、先去产品里 `grep` 那个锚点，别先怀疑产品**（主页 `@import` 拉 Google Fonts ⇒ 超时**假红**）；判回归**拿改动前的副本跑同一个 harness**。⚠⚠ **套件收尾的 `rmSync(profile)` 会卡死整层**（几百文件的 profile **永不返回**）；⚠⚠ **汇总行写在 `finally` 之后** ⇒ 卡住就**连汇总行都没有** ⇒ 一律派 `spawn(detached)` 删（⚠ 同步 `rmSync` 的 `_purge-tmp.js` 是**故意保留**的）。
- ⚠⚠ **「猜」和「决议」是两步 ⇒ 断言要打在真正决定行为的那一步**（只测「猜」会让真 bug 全绿；「量得没错但量错了对象 = 没量」），**「只有它能答」自己也要核**（六之三十三）。⚠⚠ **「这一步没做」的路径必须自己喊出来**（静默降级比直接报错难查，六之三十五）。⚠ **文档里写死的数字要么改推导式、要么配断言盯着**（六之三十六）。⚠⚠ **外部 API「形状对」≠「那个方法存在」** ⇒ 拼 URL 前先核**那条资源的方法清单**；**从同类产品抄不到 = 这条路是自己加的**（六之四十三）。⚠⚠ **导出到外部格式判据是往返**（喂回自己的解析器逐字段比）；**目标格式自带补全时，少写安全、写错灾难**（六之六十一）。
- ⚠⚠ **CSS 算不出「元素在视口里的 x」** ⇒ 挂在**按钮**上的弹层在会折行的容器里**必然**出界（窄屏工具栏折行 + `84vw`）。**调 `max-width` 治不了** ⇒ **换 containing block**（details 退回 `static`、容器加 `position:relative`、`left`/`right` 一起给）。⚠ 覆盖要写在被覆盖规则**之后**；⚠ 换之前确认容器**不裁剪**（六之六十二）。⚠⚠ **选择器过度匹配 ⇒ 把「测试挑错元素」报成「产品坏了」** ⇒ **下标是假设，先加「名字与顺序对得上」的结构锚点**（六之六十三）。
- ⚠⚠ **「过时断言」是「永真断言」的镜像** —— 产品改了**人话**、断言没跟着改 ⇒ 套件**一直红**（红久了没人看）。⚠⚠ **`grep` 产品会骗人**：旧串往往**还剩在注释里** ⇒ 只能**跑一遍看它红**；引用人话时**只守语义不守整句**（六之四十八）。⚠⚠ **「注入点唯一」挡不住「没人跑」** ⇒ 探针的 `from` 选**结构性**的，**别选人话**（六之四十九）。⚠ **同一个坑只修踩过的那一处 = 把坑留给隔壁** ⇒ 修完 `grep` 全部同类守卫。⚠⚠ **反面是「过时文档」** ⇒ **动手写工具前先 `grep` + 看技能**。
- ⚠⚠ **harness 自己的结构缺陷会伪装成「产品坏了」**：端口写死 / 盲等 `sleep` ⇒ `vertex-verify` 打 **`1 通过 / 1 失败`**，而那**唯一通过的恰恰是「零异常」** ⇒ **「通过数 = 1」且那条是零报错时，先怀疑加载没完成**；**「假红」必须靠「同一套单跑是绿的」证伪**（六之五十）。⚠⚠ **驱动坏掉 = 全部 `0.0s` + 每套 `[无]`** ⇒ **同一件事有几份实现就要改几份**（六之五十一）。⚠ **表里的数字有两种**：写死的会红、**推导的永远不会红** ⇒ 只能**拿实测跟表对**（六之五十二）。
- ⚠ **反向测试族那几条**：**别在反向测试跑着的时候改产品**（它从内存基线写回磁盘 ⇒ **静默盖掉**；kill 后留 `.bak` + 一份被注入过的产品，套件下次拒跑，那是对的）（六之三十四）；改完套件先跑 `_verify/_lint-suites.js`（模板串里的反引号会让报错指向**函数开头**）（六之三十七）；**注入要窄到只打它声称打的那件事**；**一份逻辑 N 份实现 ⇒ 探针逐针点名**（六之四十一/四十二）；**「函数写好了」≠「被调用了」** ⇒ 覆盖盯**调用点**、场景走**真实请求路径**（六之四十）；**逐份核「调用点传的参数」**（六之四十五）。
- ⚠⚠ **`w:0` + computed 有值 = 三种成因**（① 刚解析没布局 ② **整帧从没被布局** ③ 在 `display:none` 里）⇒ **判据 = 量 `document.body` 的 rect**（body 也 0 ⇒ ②，**永久**）⇒ 宽度断言**前面**必须先断言「这一帧已布局」。⚠⚠ **「单跑是绿的」只证明「负载低时窗口短」，不证明机制**；⚠⚠ **读数可疑时换「不同机制」的判据**（截图走合成器）（六之五十七 · 六之六十）。
- ⚠⚠ **「设 `value` + 派发事件」对「依赖浏览器怎么处理这个值」的行为无效** —— `value` 被规范**抹掉 `\r`/`\n`**（`number` 非法字符、`maxlength` 截断同族）⇒ 走**真会产生那个值的那条路** ⇒ **UI 的承诺没有断言看着 = 你在静默违约**。⚠⚠ **合成事件不执行默认动作** ⇒ 判「有没有接管」只认 **`defaultPrevented`**（六之五十九）。⚠ 组字中的回车是「选字」，守卫 `isComposing || keyCode===229` **要配正向对照**（六之五十八）。
- ⚠⚠ **子串断言 ≠ 符号断言**：`b'aiAbort' in dex` 在方法改名成 `aiAbortZZZ` 时**照样绿** ⇒ **改名后没有任何一层会报**。要「就叫这个」得解析 dex 的 `string_ids` 表比**整串**；只能子串的那些**单独写、说清它弱一档**，并配**负对照**（六之六十五）。
- ⚠⚠ **harness 死掉时「0 条红」==「全绿」**（注入落错缩进 ⇒ `IndentationError` ⇒ **一条 ❌ 都没有**）⇒ 比红行集合**之前**先断言「跑到收尾行」——**伪装成产品全绿更危险，你不会去查它**（六之六十六）。⚠⚠ **`rm -rf` 静默失败 = 顺序竞态，不是删法坏了**（purge 写在 `exit 0` **之前**、而停子进程的 `trap … EXIT` 要退出才跑；`set -uo pipefail` **没有 `-e`** ⇒ 无声）⇒ **读数可疑先怀疑时序**。⚠ 清不掉的后果是**拿上一轮产物当真值**（六之六十七）。⚠ **闸门本身要反向测**；**探针造的文件无条件删**、用 `atexit` 兜三条退出路径（六之六十八）。
- ⚠⚠ **探针自己的假红有两种，都伪装成「产品坏了」**：① **跨步骤复用的变量被覆盖**（错在**数据流**）；② **写死的注入目标随产品漂** ⇒ **目标改成从产物里枚举**。判据：**报红先问「红的是产品还是探针」**，最快的分法是换一条不依赖那个假设的取值路径再量一次（六之六十九）。⚠⚠ **文档里写死的数字比代码里的更危险**（没有断言盯着、**精确到个位反而更可信**）⇒ **能算的就让程序算出来打给读者看**（六之七十）。⚠ **反漂移扫描要排除探针自己**，并配一条「生产侧确实有它」的正向断言。
- ⚠⚠ **构建脚本三条**：**签名身份 = 往返判据**（keystore SHA-256 == APK SHA-256；⚠ 比较前各自校验 `^[0-9a-f]{64}$`，否则「都解析失败」⇒ 空 == 空 ⇒ 绿）；**`set -e` 对 AND-OR 列表里「非最后一项」失效**（`build.sh:119` 的 `node --check` 其实没在把关）；**没有 timeout 的等待把失败伪装成挂起**（六之七十二 · 六之七十三 · 六之七十四）。
- ⚠⚠ **「标了标记」≠「真的去兑现」** ⇒ 跨函数的「生产 → 消费」两端都要测（消费端把**换 token 那一步换成桩**）；**数组判据一律「数出来跟期望比」、不用 `every`/`some`**（兜底 `arr()` 造永真断言、不兜底让整套崩掉 ⇒ 探针「改键名」别「删结构」）；**节与节之间有隐式契约**（上一节的收尾还原是下一节的前提）（六之七十五 · 六之七十六 · 六之七十七）。

## ⑧ 验证习惯（展开版 = `RULES.md` 六）

> ⚠ **通用手法已收进用户级技能 `verify-single-file-html-app`**（完整版）；这里只留**项目特有**的。

**最常复发的几条**
- ⚠ **新增「某件事发生了」的断言，必须配「这件事不该发生」的对照组** —— 没有对照组它可能**永远为真**。⚠ **断言的方向本身就是需求**（「在外面 / 在里面」是两个产品行为）：用户改主意时**先改断言、看它红，再改产品**，否则分不清「需求变了」和「我改坏了」。⚠ 折叠面板（`grid-template-rows: 0fr` + `overflow: hidden`）**裁切不影响 `getBoundingClientRect()`** ⇒ 判「收起了看不见」必须用**命中测试**。
- ⚠⚠ **反向测试的 `red`/`green` 名单是手抄的，手抄的会漂** ⇒ 跑探针**之前**先核「这些名字在基线里真的 ✅ 过吗」，对不上就**直接退出**（别浪费后面几次整跑）。⚠ **`green` 里放一个不存在的名字最阴** —— 「对照组一条都没红」**天然成立**，对照组被悄悄削弱而探针照样全绿（`red` 里放不存在的名字会红得很吵）。⚠ 抽 ✅ 名字**两边都要 `trim`**（`check('  是摊平…')` 的名字自己带前导空格，正则的 `\s+` 会吃掉它 ⇒ `indexOf` 永远 -1）。⚠ **失败项列表符两套件不一样**（`-` vs `·`），照抄上一套的 `failsOf` 会**一条都匹配不上，而且表现为「对照组没红 ✅」** —— 看着像过了。（动画别睡固定值那条已移进技能。）⚠ **改了靶子套件的断言名，要重跑对着它的反向测试** —— 改名也会让名单腐烂，而且不报错。
- ⚠ **反向测试要注入到产品里，不是只改断言**（撤掉修复重跑，确认**恰好那几条**变红、对照组仍绿）；⚠ **注入器要自包含**（备份→注入→断言→还原→核字节），别留手动 `--restore`；**跑完必核产品哈希**。
- ⚠⚠ **绿 ≠ 验证过了，只等于「这次没红」—— 反向测试要定期重跑**。⚠ **「跑完了」≠「每条断言都跑到了」**：提前 `process.exit()` 会静默吃掉后面的断言。**锚点一律选结构性的。**
- ⚠ **「某件事从来没发生过」要拿当时的快照支撑，不能靠回忆**（批量 Edit 漏语句有两种形态：没落盘 / 落盘后被后续批量覆盖 —— 事后 grep 一模一样）。

**快路径 `check.js`（`G:\saki\_verify\`）**
- 改完先跑 `node check.js`：它自己抽 `saki.html`、自己 `vm.Script` 解析，**不用先 `extract.js`**。**5 项**：`SYNTAX` / `MISSING` / `DUPLICATE literal ids` / `UNDECLARED` / `ESCAPE-GATE`。⚠ **它读的是页面不是生成物** —— **过时的输入比没有检查更坏**。
- ⚠ **转义闸门**：判据 = 抹白已安全包装后剩下的 `+ 变量` **多重集**跟 `ESCAPE_ALLOW` 逐字一致（**用多重集不用集合**；**新加构建函数必须来改白名单**）。⚠ **两种「已声明」口径不能混用**：内联 handler 那项**只要顶层声明**，推导式那项才用完整口径。

**跑套件**
- ⚠ **整跑一律用 `run-all.js`**，别手写 `for` + `grep`/`tail`（汇总行两种格式，只匹配一种会让那几套**静默变空行**）。**「看得见」≠「检查过」。** ⚠ runner 把三件事变**硬错误**：收尾行解析不出 / 目录里有未分类 `.js` / 有失败项；⚠ **故意不写死期望总数**；⚠ **枚举不完整时不会红，只会少走**。⚠ **改了哪个套件就单跑哪个**。⚠ **外部那份还多一道**：汇总行算出来是**负数**（或分母 0）⇒ `BAD-SUMMARY` 硬错误 —— 实测 `-1/0 通过` 被正则啃成 `1/0` ⇒ `fail = -1` ⇒ 原判据 `fail > 0` 不成立 ⇒ **整层跑空却打 ✅、退出码 0**。⚠ **本地那 15 套不需要这条**（正则要求两边都是数字，匹配不上 ⇒ 走「解析不出」那条）。
- ⚠⚠ **但它抓不到「某套只跑了一部分」** —— 实测**并行跑两套 harness**时，外部 Chrome 层只跑了 **1/371** 条、汇总行照样解析得出，runner 照样打「✅ 全部通过」、退出码 0（本地那套则被 SIGTERM）。⇒ **两套 harness 一律串行**、各自 timeout **≥ 900 s**；跑完**拿逐套数字跟 `README` §7 表对一遍**（那张表的第二个用途）。
- ⚠ **管道之后的 `$?` 是 `tail` 的退出码，不是被测进程的** ⇒ 要量被测进程就**分开跑**。（完整版在技能里。）**量错了对象 = 没量。**
- ⚠⚠ **`Page.loadEventFired` 等不到时，先量网络，别先怀疑产品。** 主页一条 `@import` 拉 Google Fonts（3 字族 → **24 个 `.woff2`**），`load` 要等它们全部结束；当前网络下 `fonts.googleapis.com` **一个请求约 4 s** ⇒ 原来 15 s 的导航超时**假红**（`readyState` 停在 `interactive`，页面完全正常）。⚠ **判是不是回归的固定手法：拿改动前的副本（`saki - 副本 (N).html`）跑同一个 harness** —— 两边都卡 = 环境，只有新的卡 = 回归。⚠ 这是**网络**超时不是动画超时，别照「几百毫秒」配（已抽 `NAV_LOAD_TIMEOUT = 60000`）。
- ⚠ **`NOT FOUND —— 锚点变了` 时，先去产品里 `grep` 那个锚点，再改探针** —— 「代码不在」和「代码挪了」从探针这侧看**一模一样**。⚠ **探针收尾：`kill()` 在前、删 profile 在后**，句柄要挂**模块作用域** —— `.finally()` 的回调**看不见** async IIFE 里 `const` 的变量，`try{ch.kill()}catch{}` 吞的是 `ReferenceError`，**长得跟「清理成功」一样**（实测漏 3 个目录）。⚠ 抄同族文件时，**看着像装饰的那半句往往才是让清理生效的**。

**这个项目特有的坑**
- ⚠ **`saki.html` 是 CRLF**，JS 里 `.` **不匹配 `\r`** → `/\/\/.*$/` **整条匹配失败**（不报错，只安静地给出错的数）。**凡是用 `$` 锚行尾的正则，先问「这文件是 CRLF 吗」。** ⚠ Git Bash 的 `grep -c $'\r'` 对 CRLF 文件会报 0（**不可靠**）—— 要数就 Node 读 `latin1` 后 `match(/\r\n/g)`。
- ⚠ **写死清单 / 写死数字的断言每次加东西都会来收一次「红」的账** → **改推导式 / 跟基线比**；⚠ 最阴的一种：遍历清单是**字面量数组**，新项不在里面 → **根本不会红**，只是静默少走。⚠ **探针自己造的文件要无条件删**（别写「备份存在才还原」—— 文件本就不在时会**把垃圾留在目录里**且不说）。⚠ 套件时序坑（`ev(..., true)` 不等 Promise / mock 与 `stream` 要一起改）见 `RULES.md` 六。
- ⚠⚠ **新增功能可能让旧套件的「前提」失效，而不是打坏产品。** 手机菜单让 `#ai-card` 在手机视口下默认 `display:none` ⇒ 外部层那些「移动端触控尺寸」断言**集体假红**（rect 全 0）。判据：**看数值是不是全 0** —— 全 0 通常意味着「元素不可见」，不是「尺寸不达标」；修法是**让断言走真实路径**（手机用户 = 点菜单 → 全屏），不是把产品改回去。
- ⚠ **隐藏一个靠 class 变 `position:fixed` 的卡片，必须写 `:not(.全屏类)`** —— 否则全屏被 `display:none` 一起压掉，而 class 照样加得上 ⇒ **只断言 class 抓不到，必须断言 computed `display`**。

- **⑥ 运行时判定（`RULES.md` 四）**：渲染条件**只有两条**（在围栏里 + 同时有 `<body>` 和 `</body>`），满足后当作**独立网页塞进 iframe**，`<style>`/`<script>`/外链资源**全可用**（旧笔记「只能内联」**已推翻**）。**「原样解析」= 运行时怎么解析，编辑器就怎么解析**；**拆不动就原样留成「高级 HTML」块**，绝不静默丢内容。⚠ **内联永远赢过 class** → 按**属性**粒度抑制；⚠ **回写闸门三层**，强写只有 `stSbSync(true)`，**绝不静默覆盖别人手写的内容**。
- **⑦ 自由摆放与尺寸（`RULES.md` 五）**：偏移**必须是相对定位**（`position:relative;left:Xpx;top:Ypx`，绝对定位会脱流），**两个偏移都是 0 时一条声明都不写**。⚠ **读回尺寸前先跟「生成器基线」比**（`stSbSizeBaseline`），否则分割线自己那条 `height:1px` 会被读成用户设的；**尺寸只认 `px`**；⚠ **「纯定位壳」要拆**（`stSbOffOnlyWrapper`），否则下一轮**再解析偏移翻倍**（8→16）。

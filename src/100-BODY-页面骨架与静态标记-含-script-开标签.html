🎭 酒馆模式 · 角色卡
实际提示词结构
角色卡支持 SillyTavern 的 PNG 卡（读 chara / ccv3 数据块）与 JSON 卡（V1 / V2 / V3）。
卡里自带的世界书会自动读入，也能单独导入世界书 JSON。
世界书的激活规则（关键词 / 次关键词逻辑 / 常驻 / 概率 / 包含组 / 递归 / 黏性冷却延迟 / 装饰器 @@activate）与插入位置和深度（↑Char / ↓Char / ↑AT / ↓AT / @D / ↑EM / ↓EM / Outlet）都按 SillyTavern 的语义执行：每个位置会像 ST 一样拼成一条消息，↑AT / ↓AT 则夹住作者注释整体注入，并且不做 token 预算截断 —— 命中的条目会全部插入。
提示词预设决定「提示词由哪些槽组成、按什么顺序排、插在哪」—— 和 ST 的 Chat Completion 预设同一套模型（prompts + prompt_order），ST 导出的预设 JSON 可以直接导入。内置预设只读，一编辑就自动生成你自己的副本。
和系统提示词互斥：开启后只用角色卡里的提示词（system_prompt / 描述 / 性格 / 场景 / 示例对话 / 历史后指令），原系统提示词会被关掉。
